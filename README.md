# Таблица — тренажёр умножения

Сайт: https://fenix007.github.io/multiplication-table-trainer/

Веб-тренажёр, который переводит таблицу умножения из «считаю» в «знаю наизусть». Один HTML-файл, без сервера, работает офлайн, ставится на планшет как приложение (PWA).

## Как это работает

- **36 фактов** вместо 100: 2–9 × 2–9 с учётом перестановки (7×8 = 8×7). ×1 и ×10 — правила, их не учим.
- **Диагностика**: каждый факт получает статус *знаю* (верно и быстрее 3,5 с), *считаю* (верно, но медленно) или *не знаю*.
- **Интервальные повторения на уровне факта** (6 уровней): быстрый верный ответ поднимает уровень и отодвигает повтор (сейчас → 10 мин → 1 д → 3 д → 7 д → 30 д), ошибка сбрасывает в ноль.
- **Лимит времени на ответ** — главный механизм против «досчитывания»: не успел — видишь ответ и переписываешь его.
- **Режимы**: Проверка · Повторяю · Учу новое (по 3–4 факта, от лёгких таблиц к тяжёлым) · Спринт 60 с · Карта таблицы.
- **Экран родителя** (PIN по умолчанию `1234`): тепловая карта времени ответа, слабые места, журнал занятий, динамика по дням, настройки порога и цели дня, экспорт JSON.

Прогресс хранится в браузере (localStorage) на том устройстве, где идут занятия.

## Установка на планшет

Откройте адрес GitHub Pages репозитория в браузере планшета и выберите:

- **iPad (Safari)**: Поделиться → «На экран „Домой“».
- **Android (Chrome)**: меню ⋮ → «Установить приложение» / «Добавить на главный экран».

После первого открытия приложение работает без интернета.

## Структура

```
index.html                 приложение целиком (движок + интерфейс)
manifest.json              PWA-манифест
sw.js                      сервис-воркер (офлайн-кэш)
icons/icon.svg             исходник иконки
tools/make_icons.py        генерация PNG-иконок (Pillow), выполняется в CI
.github/workflows/pages.yml деплой на GitHub Pages
```

## Локальный запуск

Достаточно открыть `index.html` в браузере. Для проверки PWA-режима нужен любой статический сервер, например `python3 -m http.server`.
